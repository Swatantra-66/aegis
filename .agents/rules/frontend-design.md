# Aegis Design System & Anti-AI-Slop Rules

## 1. Zero AI Boilerplate Mandate
- **NEVER** use default Bootstrap/Tailwind card grids, generic gray utility boxes, or plain white card layouts.
- **NEVER** use generic stock placeholder text ("Lorem ipsum", "John Doe", "Manage your account efficiently"). Use realistic, high-fidelity cybersecurity telemetry and cryptographic terminology.
- **NEVER** use standard flat HTML tables without custom typography, status indicator pills, and subtle border lines (`var(--line)`).

## 2. Visual Hierarchy & Aesthetic Standards
- **Color Palette**: Ultra-deep pitch black baseline (`#000000`), deep midnight backgrounds (`#080808`, `#0c0c0c`), sharp hairline borders (`1px solid rgba(255, 255, 255, 0.07)`), and purposeful accent highlights (Neon Security Green `#00FF66`, Hyper Orange `#FF5A1F`, Deep Purple `#863bff`).
- **Typography**: Editorial Brutalism — high contrast numerals, tabular figures (`font-variant-numeric: tabular-nums`), monospaced micro-telemetry (`var(--font-mono)`), and sharp display headings with tight tracking (`letter-spacing: -0.03em`).
- **Surface Elevation**: Deep subtle glassmorphism (`backdrop-filter: blur(16px)`), micro-dot grids (`sirnik-grid-bg`), and radial glow accents rather than heavy opaque drop shadows.

## 3. Micro-Interactions & Animation
- All page entries MUST use coordinated GSAP context stagger animations (`stagger: 0.06`, `ease: 'power3.out'`).
- Interactive elements must provide crisp hover transitions (`cubic-bezier(0.16, 1, 0.3, 1)`), subtle scale lifts (`1.02x` - `1.05x`), and glowing border highlights.
- Data counters and telemetry numbers should format with clean padding and monospaced alignment.
